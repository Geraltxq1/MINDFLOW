# MINDFLOW
MindFlow es una app de trivia donde el usuario elige una categoría (Tecnología, Matemáticas, Arte, Ingeniería o Ciencia) y una dificultad, luego la IA genera 10 preguntas únicas en tiempo real. Cada pregunta tiene un timer de 15 segundos y al responder se muestra una explicación generada por IA. Al terminar el quiz el jugador gana XP, sube de nivel y recibe monedas que puede gastar en accesorios para su avatar. El sistema tiene ranking global con podio, logros desbloqueables, racha de días consecutivos y un reto diario con recompensas dobles — todo construido sobre React Native, Node.js y Firebase, con GPT-4o generando el contenido dinámico.
